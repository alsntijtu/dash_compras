Conectar aba do Google Sheets

Configure a fonte CSV da aba selecionada. Cada aba do dashboard pode apontar para uma aba diferente da mesma planilha.

  1. 1. Abra a planilha no Google Sheets
  2. 2. Clique em Arquivo → Compartilhar → Publicar na Web
  3. 3. Selecione a aba que deseja publicar e escolha Valores separados por vírgula (.csv)
  4. 4. Clique em Publicar e copie o link CSV gerado
Aba selecionada: GERAL
O link pode conter gid=.... O dashboard usa esse identificador para carregar a aba correta.
